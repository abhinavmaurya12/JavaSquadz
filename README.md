## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/abhinavmaurya12/CodeSquadz.git
```

### 2. Open the project

Open the repository in:

* IntelliJ IDEA
* Eclipse
* VS Code
* NetBeans

### 3. Compile a Java file

```bash
javac FileName.java
```

### 4. Run the program

```bash
java ClassName
```

For example:

```bash
javac Array_home25.java
java Array_home25
```
