# ☕ JavaSquadz

### Java Programming • Core Java • OOP • DSA • Practice

**JavaSquadz** is a public Java programming repository focused on learning Java through practical coding, concept implementation, problem solving, and continuous practice.

The repository contains programs and examples covering **Core Java, OOP, Arrays, Strings, Patterns, Exception Handling, Multithreading, File Handling, I/O Streams, Collections, AWT/Swing, Packages, Serialization, Reflection, Network I/O, Garbage Collection, and more.**

> 🚀 **Learn Java by writing code, understanding concepts, solving problems, and building strong programming fundamentals.**

## ▶️ Run the Programs

### 1. Clone the Repository

```bash
git clone https://github.com/abhinavmaurya12/JavaSquadz.git
```

### 2. Open the Project

Open the repository in any Java-compatible IDE:

- IntelliJ IDEA
- Eclipse
- VS Code
- NetBeans

### 3. Compile a Java File

```bash
javac FileName.java
```

### 4. Run the Program

```bash
java ClassName
```

### Example

```bash
javac Array_home25.java
java Array_home25
```

> Make sure the Java class name and filename match when using a `public` class.
